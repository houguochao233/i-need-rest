# I Need Rest

### 一个轻量、有趣、可恢复的 Windows 伪蓝屏工具

想暂时离开电脑，但又需要一个看起来合理的理由？

**I Need Rest** 可以把快捷方式或普通文件临时变成全屏“系统故障”风格的伪蓝屏入口，配合倒计时、百分比和经典 Windows 蓝屏主题，营造出“电脑正在恢复”的视觉效果。

它不触发真实蓝屏，不修改系统，不安装驱动，所有操作都可以恢复。

## ✨ 它能做什么？

- **伪蓝屏视觉效果**：全屏覆盖桌面，模拟 Windows 系统故障或恢复界面。
- **多种系统主题**：支持 Windows 11、Windows 10、Windows 7、Windows XP 风格。
- **Windows 10 经典效果**：包含 `:(`、二维码和百分比进度显示。
- **文件临时接管**：支持 `.lnk` 快捷方式和普通文件，文件夹暂不支持。
- **自动备份**：接管前自动保存原文件，避免误操作导致文件丢失。
- **多种恢复方式**：一次使用后恢复、蓝屏结束后恢复、手动恢复。
- **名称和图标保持**：快捷方式会尽量沿用原有名称、图标和图标索引；普通文件使用 Windows 文件关联图标。
- **轻量运行**：不常驻后台，不主动刷新 Explorer，优先减少桌面闪烁和卡顿。

> 这不是恶意软件，也不会制造真实系统故障。它只是一个用于娱乐、演示和桌面视觉效果的本地小工具。

前往仓库的 [Releases](https://github.com/houguochao233/i-need-rest/releases) 页面，优先下载最新版本的 `I-Need-Rest-portable.zip`。

解压后双击文件夹内的 `I-Need-Rest.exe`，不要只把 EXE 单独拿出来。首次运行时建议将整个程序文件夹放到一个不会被随意移动的位置；程序会在 EXE 同目录创建 `data` 文件夹，用来保存备份和恢复记录。

## 📖 使用方式

1. 启动 **I Need Rest**。
2. 将快捷方式或普通文件拖到窗口中，也可以点击区域选择文件。
3. 设置蓝屏时长、开始百分比、主题和退出热键。
4. 选择恢复模式。
5. 点击“生成蓝屏快捷方式”。
6. 双击生成的文件，即可进入伪蓝屏界面。
7. 使用界面显示的热键退出，或等待设定时间结束。

### 恢复模式

- **一次后立即恢复（推荐）**
  - 双击代理后先恢复原文件，再显示伪蓝屏。
  - 适合只想临时使用一次的情况。

- **蓝屏结束后恢复**
  - 伪蓝屏结束或退出后，自动恢复原文件。

- **手动恢复**
  - 保持伪蓝屏代理，直到在主程序中点击“恢复选中项”或“恢复全部”。

## 🗂️ 文件和快捷方式是如何处理的？

### 快捷方式 `.lnk`

程序会先把原快捷方式备份到 EXE 同目录的 `data\backups` 中，然后在原路径写入伪蓝屏代理。代理会尽量保持原快捷方式的名称和图标，恢复时再用备份替换回来。

### 普通文件

Windows 本身不能让一个普通文件在保留原内容的同时拦截双击行为，因此程序会：

1. 把原文件移动到 EXE 同目录的 `data\backups\<项目ID>`；
2. 在原位置生成一个带 `.lnk` 的伪蓝屏代理；
3. 使用 Windows 对该扩展名解析出的关联程序图标；
4. 将备份文件设置为隐藏，避免原文件在备份目录中暴露；
5. 恢复时删除代理，把原文件恢复到原路径，并还原原来的文件属性。

如果系统开启了“显示已知文件类型的扩展名”，普通文件代理可能显示额外的 `.lnk` 后缀，这是 Windows 的显示规则，程序不会修改系统设置。

## ⚠️ 重要注意事项

### 桌面图标位置

当前版本优先保证操作流畅，已经关闭了桌面图标位置读取和恢复功能。因此：

- 恢复快捷方式或普通文件后，图标可能移动到桌面排列的最后方；
- 图标名称和图标尽量保持不变，但位置暂时不保证回到原处；
- 这样可以减少 Explorer 通信、桌面刷新和操作卡顿。

### 使用期间不要移动程序文件

程序的代理快捷方式需要从 EXE 所在路径启动，使用期间请不要：

- 移动或删除 EXE 所在文件夹；
- 删除 `data` 文件夹；
- 手动删除备份文件；
- 在程序运行过程中重命名程序文件夹。

如果程序异常退出，重新打开管理器后优先点击“恢复全部”。
