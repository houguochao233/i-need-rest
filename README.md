# 伪蓝屏快捷方式工具

一个轻量、本地、无害的 Windows 工具：把指定的快捷方式或普通文件临时转换为“伪蓝屏”启动文件。双击后显示全屏蓝屏风格计时界面；它不会触发真实系统蓝屏、重启电脑、修改注册表或设置开机自启。

## 功能

- 支持拖入或选择 `.lnk` 快捷方式；也支持普通文件，暂不处理文件夹。
- Windows 11、Windows 10、Windows 7、Windows XP 四种蓝屏视觉主题。
- Windows 10 主题包含 `:(`、二维码和百分比计时效果。
- 支持自定义蓝屏时长、起始百分比、退出热键和恢复方式。
- 自动备份原快捷方式/文件，可恢复选中项目或恢复全部项目。
- 支持删除记录；删除未恢复项目时会先提示并自动恢复。
- 生成时尽量保留原快捷方式的名称和图标。
- 当前版本优先减少 Explorer 刷新和卡顿，**暂不保证恢复后桌面图标回到原来的排列位置**。

## 环境与运行

需要 Windows、Python 3.11 或更高版本，以及项目依赖：

```powershell
python -m pip install -r .\requirements.txt
python .\bsod_shortcut.py
```

也可以直接双击项目中的 Python 启动方式（前提是系统已正确关联 Python）。首次运行会在项目目录生成 `data` 文件夹，用于保存备份和记录。

> 使用期间不要移动、重命名或删除项目目录。蓝屏代理需要从项目目录启动；如果项目目录不可用，代理可能无法打开，但备份文件通常仍在 `data\backups` 中。

## 基本操作

1. 启动程序。
2. 将一个 `.lnk` 快捷方式或普通文件拖入窗口，也可以点击拖放区域选择文件。
3. 设置蓝屏时长、开始百分比、主题和退出热键。
4. 选择恢复方式：
   - **一次后立即恢复（推荐）**：双击代理后先恢复原文件，再显示伪蓝屏；适合不希望文件长期处于代理状态的情况。
   - **蓝屏结束后恢复**：蓝屏退出或计时结束后恢复原文件。
   - **手动恢复**：一直保留代理，直到在管理器中点击恢复。
5. 点击“生成蓝屏快捷方式”。
6. 双击生成后的文件，按界面显示的热键退出伪蓝屏。

## 快捷方式模式

对于 `.lnk` 文件，程序会：

1. 将原快捷方式复制到项目的 `data\backups` 目录；
2. 在原路径写入蓝屏代理快捷方式；
3. 尽量沿用原快捷方式名称和图标资源；
4. 根据选择的恢复方式恢复原 `.lnk`。

如果快捷方式使用了自定义图标、图标索引或目标程序图标，Windows Explorer 的显示结果可能受图标缓存、系统缩放、主题和文件关联影响，因此只能保证尽量一致，不能承诺所有系统环境下像素级完全相同。

## 普通文件模式

普通文件无法在保留原文件的同时直接拦截双击，因此程序会：

1. 将原文件移动到 `data\backups\<项目ID>`；
2. 在原位置创建带 `.lnk` 的蓝屏代理；
3. 代理使用原文件作为图标来源；
4. 恢复时删除代理，并把备份文件复制回原路径。

如果 Windows 设置为显示“已知文件类型的扩展名”，桌面上可能会显示额外的 `.lnk` 后缀，这是系统显示规则，程序不会修改系统全局设置。

## 恢复与删除注意事项

- “恢复选中项”只恢复当前选中的记录；“恢复全部”恢复所有仍处于代理状态的记录。
- 删除记录前会检查项目是否尚未恢复。未恢复时必须先确认，程序会先自动恢复，再删除记录和备份。
- 恢复后文件或快捷方式可能出现在桌面图标排列的最后方，或者位置发生变化。这是因为当前版本暂时关闭了桌面图标位置读取和恢复，以减少 Explorer 通信、刷新和卡顿；程序不会强制刷新桌面或重启 Explorer。
- 如果恢复期间同一路径已经存在同名文件，请先处理冲突，不要强行覆盖重要文件。
- 不要在代理仍处于使用状态时手动删除 `data`、备份目录或项目脚本。
- 如果程序异常退出，重新启动管理器后检查“已管理的快捷方式”列表，并优先使用“恢复全部”。

## 安全边界

- 这是全屏视觉模拟，不是真实系统故障。
- 程序不会拦截 `Ctrl + Alt + Delete` 等 Windows 安全组合键。
- 程序不联网、不采集数据、不修改注册表、不修改启动项、不安装驱动。
- 请只在自己拥有或获授权使用的文件上测试。
